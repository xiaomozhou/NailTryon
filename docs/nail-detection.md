# 静态照片指甲检测

本模块检测拍摄及相册选择的静态照片，不实现美甲片变形、贴合或绘制，也不改变现有生成式试戴算法。

## 流程

拍摄完成 → 读取并按 EXIF 校正照片（最长边 2048）→ 本机 CPU 实例分割 → 在原照片上显示检测轮廓 → 用户检查后使用照片，或重新拍摄。图像解码和推理不在 UI 线程运行。首次使用无需下载模型、联网或配置 API Key。

只在检测到 **恰好五片**指甲、每片模型置信度不低于 0.60、蒙版未触及照片边缘时启用“使用照片”。分割候选阈值为 0.50，框 NMS IoU 为 0.45。无检测结果、少于或多于五片、异常、低置信度、照片被裁切均不会用固定位置补齐。模型分数不等于经过校准的准确率。

指甲分割模型本身不识别左右手或指头身份。拍摄流程使用左手手背占位引导与用户确认；相册流程先使用独立手部关键点模型检查照片规范，再进行指甲分割，详见下节。相机当前不运行连续帧分析。

## 相册照片规范检查

从相册选择手部照片 → 后台读取 EXIF 校正、限长的图像 → BlazePalm 检测手部 → 手部关键点模型输出 21 个关节及左右手分数 → 检查单只左手、手背朝向、五指伸展与间距、是否裁切 → 五片指甲分割并与五个指尖一对一匹配 → 显示轮廓 → 用户使用照片后才进入现有试戴流程。

- 无手、多手、低置信度、非有限坐标、右手、手心/侧手、弯曲/并拢/交叉手指、裁切、指甲缺失/遮挡、不清晰均不能进入试戴。推理或读取异常同样不能绕过检查。
- 不合格时显示具体原因和“去拍一张”，进入现有 `HandCameraActivity` 的权限、左手占位引导、拍摄、指甲检测流程；取消拍摄后仍回到相册检查页，原选美甲款式不变。相册选择取消保持原选择照片面板；检查中返回会取消该页面任务。
- 两个手部模型采用 MediaPipe 的镜像/自拍左右手约定。本应用不对相册照片额外镜像：原始 MP-Left 分数不高于 0.20 作为当前显示照片的左手证据，手部存在分数至少 0.80；结合腕点、食指及小指 MCP 的归一化有向面积小于 -0.20 检查手背朝向与侧拍。
- 伸展判断结合 MCP→PIP→指尖的方向与长度；指间距离以掌宽和近节指骨长度归一化，并检查食指到小指的投影顺序，避免交叉。不能只用角度判断张开，因为自然分开的手指也可能近似平行。
- 指甲必须与不同手指的 DIP→指尖区域一对一匹配（轴向范围 -0.30～1.30，横向距离不超过该指节长度的 0.60），禁止仅凭“检测到五片指甲”放行样本板或无关区域。
- 所有判断针对照片呈现的手部。已镜像或后期编辑的照片无法仅靠像素恢复拍摄时的真实左右手身份；不确定时提示按引导重新拍摄。该规则和模型仍需真实手机照片校验，不能保证所有姿势和光照均正确。

## 后续贴合接口

`NailDetector.detect(Bitmap)` 返回 `NailDetection`，包含输入照片宽高、各个 `NailRegion`：

- `box`：原照片坐标，右/下边界不包含；作为局部蒙版的存储窗口。
- `mask`：窗口内按行排列的二值 ByteArray（0 背景，255 指甲），保留最大连通区域，去除孤立噪点。
- `contour`：按边界顺序排列的原照片像素坐标；只合并共线段，保留凹边。
- `center`、`axisRadians`、`orientedCorners`：像素质心、PCA 主轴和有向包围矩形，供未来定位/变形使用。主轴是无向轴，不代表甲根到甲尖的方向。
- `confidence`、`touchesImageEdge`：模型分数与是否裁切。

预处理使用等比例缩放和灰边填充，返回坐标移除填充并按实际整数缩放尺寸反变换。蒙版概率双线性采样至原图分辨率后以 0.50 二值化。结果按横向质心排列，此顺序不能代替指头身份。

轮廓展示使用独立 Canvas 图层，不写进 JPEG 或推理输入。检测结果在当前检查页面内保留；本次不新增照片/检测结果长期存储，后续贴合可直接消费上述接口。

## 验证范围与限制

专项测试覆盖非正方形照片坐标还原、概率采样、重复抑制、无效分数过滤、噪点、凹轮廓、主轴、裁切与数量判断，以及检测中/成功/失败/重拍交互。真实模型测试使用两个固定手部照片，检查五片分割、人工指定的指甲内点和皮肤/背景外点、缩放后的定位一致性，以及空白照片无虚假检测。结果轮廓图片写入 `app/build/reports/nail-detection/`，用于人工检查。

这些样本是集成回归验证，不代表各种肤色、自然短甲、遮挡或反光下的总体准确率。轮廓输出为照片上的二维区域；极端反光、模糊、侧拍仍可能不准，应重拍。尚需小米 13 实机检查拍摄延迟、内存和实际手部照片；本次不运行全量测试或打包 APK。

相册专项测试另覆盖：真实左手手背、旋转照片、镜像成的右手、单手手心、双手、非张开手势、遮挡单片指甲、空白照片，以及规范判断各拒绝分支。界面测试覆盖检查中、合格后才生成、不合格转拍摄、拍摄取消与成功返回、模型异常、不可读照片、取消选择、检查中返回。原保存/历史测试更新为使用真实合格手部样本走完检查，不绕过新增入口。
