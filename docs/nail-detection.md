# 静态照片指甲检测

本模块只检测拍摄完成的照片，不实现美甲片变形、贴合或绘制，也不改变现有生成式试戴算法。相册上传路径暂不改动。

## 流程

拍摄完成 → 读取并按 EXIF 校正照片（最长边 2048）→ 本机 CPU 实例分割 → 在原照片上显示检测轮廓 → 用户检查后使用照片，或重新拍摄。图像解码和推理不在 UI 线程运行。首次使用无需下载模型、联网或配置 API Key。

只在检测到 **恰好五片**指甲、每片模型置信度不低于 0.60、蒙版未触及照片边缘时启用“使用照片”。分割候选阈值为 0.50，框 NMS IoU 为 0.45。无检测结果、少于或多于五片、异常、低置信度、照片被裁切均不会用固定位置补齐。模型分数不等于经过校准的准确率。

该模型检测指甲，不识别左右手或指头身份。左手手背由拍摄引导与用户确认保证；不能仅凭五片指甲判断一定是左手。相机当前不运行连续帧分析。

## 后续贴合接口

`NailDetector.detect(Bitmap)` 返回 `NailDetection`，包含输入照片宽高、各个 `NailRegion`：

- `box`：原照片坐标，右/下边界不包含；作为局部蒙版的存储窗口。
- `mask`：窗口内按行排列的二值 ByteArray（0 背景，255 指甲），保留最大连通区域，去除孤立噪点。
- `contour`：按边界顺序排列的原照片像素坐标；只合并共线段，保留凹边。
- `center`、`axisRadians`、`orientedCorners`：像素质心、PCA 主轴和有向包围矩形，供未来定位/变形使用。主轴是无向轴，不代表甲根到甲尖的方向。
- `confidence`、`touchesImageEdge`：模型分数与是否裁切。

预处理使用等比例缩放和灰边填充，返回坐标移除填充并按实际整数缩放尺寸反变换。蒙版概率双线性采样至原图分辨率后以 0.50 二值化。结果按横向质心排列，此顺序不能代替指头身份。

轮廓展示使用独立 Canvas 图层，不写进 JPEG 或推理输入。检测结果在当前检查页面内保留；本次不新增照片/检测结果长期存储，后续贴合可直接消费上述接口。

## 模型与第三方材料

- 模型及两个测试照片来自 [austingg/finger-nail-seg](https://github.com/austingg/finger-nail-seg)，固定版本 `2cb37309fdea69de4fcc25cbbe1a1baf5e4b5d25`。
- 模型为仓库 `models/nail-seg.onnx`（YOLOv8s-seg，47,417,145 字节）；上游 Git blob ID：`a72775888aab612bacffff4c48669a5f67b59dc7`。
- 上游 GPL-3.0 许可证原文随模型保留在 `assets/models/LICENSE.nail-seg.txt`，测试样本同源。分发包含这些材料的应用时须遵守该许可证。本项目的 Kotlin 推理及后处理独立实现，未复制上游 Python 代码。
- [ONNX Runtime](https://onnxruntime.ai/docs/get-started/with-java.html) 1.20.0：Android 使用 Android 原生运行时；Windows 专项测试加载同版本桌面 CPU 原生运行时，执行真实模型。

## 验证范围与限制

专项测试覆盖非正方形照片坐标还原、概率采样、重复抑制、无效分数过滤、噪点、凹轮廓、主轴、裁切与数量判断，以及检测中/成功/失败/重拍交互。真实模型测试使用两个固定手部照片，检查五片分割、人工指定的指甲内点和皮肤/背景外点、缩放后的定位一致性，以及空白照片无虚假检测。结果轮廓图片写入 `app/build/reports/nail-detection/`，用于人工检查。

这些样本是集成回归验证，不代表各种肤色、自然短甲、遮挡或反光下的总体准确率。轮廓输出为照片上的二维区域；极端反光、模糊、侧拍仍可能不准，应重拍。尚需小米 13 实机检查拍摄延迟、内存和实际手部照片；本次不运行全量测试或打包 APK。
